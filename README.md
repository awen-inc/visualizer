# Audio Visualizer Studio

音源ファイルを読み込むと、**音に反応して動くビジュアライザー**をブラウザ上で作れる無料ツールです。
作った波形は、動画編集ソフトで背景や曲に重ねて使う映像素材として書き出せます。

🎧 **デモ（ブラウザですぐ触れます）** → https://awen-inc.github.io/visualizer/

---

## 特徴

- **3つの表示タイプ** … 棒 / ウェーブ / 円形を切り替え
- **音源ファイルを読み込んで連動** … 任意の曲（wav / mp3 / m4a 等）に反応
- **GUIで自由に調整** … 色・本数・高さ・位置・スケール・発光など
- **反応の作り込み** … 全体の底上げ、近傍への伝播で、有機的な動きに
- **インストール不要** … ブラウザだけで動作。サーバーもアカウント登録も不要

---

## 使い方

1. 「音源を開く」で曲を選択
2. 「再生 / 停止」で再生すると波形が動くので、GUIで見た目を作る
3. 「背景画像」で、乗せたときのイメージを確認（※出力には含まれません）
4. 「録画開始」で波形を記録（映像のみ・黒背景）。曲の終わりで自動停止、手動停止も可
5. 書き出した webm を、下記コマンドで透明背景の素材（.mov）に変換：

```
ffmpeg -i waveform.webm -vf "format=rgba,geq=r='r(X,Y)':g='g(X,Y)':b='b(X,Y)':a='max(max(r(X,Y),g(X,Y)),b(X,Y))',format=yuva444p10le" -c:v prores_ks -profile:v 4444 waveform.mov
```

6. できた素材を動画編集ソフト（DaVinci Resolve 等）で背景に重ねる。合成モードは「通常」のまま。発光が欲しければ編集側で後がけ

詳しい手順は、ツール画面内の「使い方ガイド」に記載しています。

---

## 動作環境

ブラウザ（Brave / Chrome 等）。変換に FFmpeg、仕上げに動画編集ソフトを使います（いずれも無料で揃います）。
